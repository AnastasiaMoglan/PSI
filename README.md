# Starlog

A habit tracker that turns your daily discipline into a night sky. Every completed habit lights up a new star; keep a streak alive and your stars link together into a growing constellation.

## Concept
- Each habit you complete today places a star on your personal star map.
- Consecutive days (a streak) draw a line between stars, forming a constellation.
- Break a streak and the constellation fades — but the star stays, so nothing is ever fully lost.
- Fill a constellation (e.g. 5 connected stars) to "name" it and unlock a new one to chase.

## Features (planned)
- Create habits (e.g. "Read", "Workout", "No sugar")
- Mark a habit done for the day → adds a star + extends the streak
- Missed day → streak (constellation line) resets, star remains dim
- Star map view: see all constellations built over time
- Constellation completion unlocks a new shape/pattern to aim for
